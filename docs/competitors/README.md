## パック作りでの使い方

1. **テーマが競合とかぶっていないか確認する**：まず「オンラインオリパ」のうち、ポケカを扱う稼働中の72件を見る。大手（DOPA!、クローブオリパ、日本トレカセンター、オリくじ、オリパワン など）は必ず見る。
2. **PSA10だけでは違いにならない**：一覧のジャンルにPSAと書かれているのは3件（レガリアオリパ・トレモ！・トレカマニア）だけだが、日本トレカセンター・クローブオリパ・DOPAは「PSA10確定オリパ」を定期的に出している（2026-10-14の確認）。PSA10にそろえたうえで、テーマで違いを出す。
3. **備考欄を確認する**：DOPA!、クローブオリパ、日本トレカセンター、オリパワン、エクストレカは「2026/9 集団訴訟の被告」、オリくじ、ポケットクロスは「消費者庁への申出対象」と書かれている。告知文や還元の見せ方を参考にするときは、このメモに注意する。

## 注意

- Claudeの作業環境からは各サイトを直接開けない（Web検索だけ使える）。サイトに今どんなガチャが出ているかは、人が開いて確認する。
- 一覧は2026-10-14時点。サイトの開始・終了は多いので、元のスプレッドシートが更新されたらこのCSVも作り直す。
