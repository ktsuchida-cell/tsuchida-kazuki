# DM先の選び方

他社のオリパを買って、X（旧Twitter）に前向きな投稿をしている人に、メタオリパからDMを送る。**毎日5名**を選ぶ。

- 記録：[DM候補リスト.csv](DM候補リスト.csv)（送った人・予備・除外を全部ここに残す。同じ人に二度送らないため）
- Claude Code に「今日のDM先を選んで」と頼むと `.claude/skills/oripa-dm` の手順で選ぶ。

## 選ぶ条件

全部に当てはまる人を選ぶ。

1. **個人のアカウント**。オリパサイトの公式・中の人、カードショップ、オリパ情報・まとめ・紹介コードを配るアカウント、YouTuberなどの発信者は除く。
2. **オリパを買うことに前向き**。当選報告、「楽しい」「また引く」「明日も」「これからもよろしく」、おすすめのサイトを探している、など。
3. **ポケカ**の投稿（メタオリパはポケカだけなので、ワンピース・遊戯王だけの人は除く）。
4. **メタオリパのお客さんではない**。投稿やプロフィールにメタオリパが出てくる人、メタオリパのアカウントをフォローしている人は除く。
5. **まだ送っていない**。DM候補リスト.csv にいる人は選ばない（予備は使ってよい）。

## 送らない人

- 負けが込んでいる・後悔している投稿をしている人（「累計マイナス」「爆死」「やめたい」「借金」など）。
- 未成年かもしれない人（プロフィールに学年・年齢・「学生」などがある、「お年玉で」など）。
- オリパに批判的な人。

## 優先順位

1. 新しいサイトを探している人（「おすすめ教えて」「乗り換えた」など）
2. 投稿が新しい人（直近3か月を優先）
3. 続けて引く気がある人（「明日も」「また」など）
4. 高額カードを当てた人

投稿日は投稿URLの数字から分かる：`python3 -c "import datetime as d,sys;print(d.datetime.fromtimestamp(((int(sys.argv[1])>>22)+1288834974657)/1000,d.timezone(d.timedelta(hours=9))))" <statusの後ろの数字>`（日本時間）

## 送る前に人が確認すること（1人1分）

Claudeの作業環境からはXを開けないので、Web検索に出た投稿だけで選んでいる。送る前にプロフィールを開いて確認する。

- 今もオリパの投稿をしているか（検索に出るのは数か月前の投稿が多い）
- 上の「送らない人」に当てはまらないか、メタオリパをフォローしていないか
- DMを受け付けているか。閉じていたら送らずに、予備から1人足す（投稿へのリプライで宣伝はしない）

## DMの文面

1人ずつ投稿に触れて書く。同じ文面を何人にも送ると、Xでスパム扱いされやすい。

**当選報告をしていた人**

> はじめまして、ポケカのオンラインオリパ「メタオリパ」です。
> 〇〇（当てたカード）の当選報告を拝見しました、おめでとうございます！
> メタオリパでも△△（今出しているガチャ）を出しているので、よかったら一度のぞいてみてください。
> https://metaoripa.com/
> 突然のご連絡失礼しました。

**おすすめのサイトを探していた人・乗り換えた人**

> はじめまして、ポケカのオンラインオリパ「メタオリパ」です。
> オンラインオリパを探されている投稿を拝見して、ご連絡しました。
> メタオリパは△△（自社の特徴）のオリパを出しています。よかったら一度のぞいてみてください。
> https://metaoripa.com/
> 突然のご連絡失礼しました。

- 還元率や当たりやすさを約束する書き方はしない。
- 新規特典を書くときは、今実際にやっているものだけにする。
- DMで「投稿してほしい」とお願いして、お礼（ポイントなど）を渡すときは、投稿に「#PR」などの表記をしてもらう（ステマ規制）。

## 記録のつけ方

- 選んだ人は「区分」を `送る`、「選定日」に日付。DMを送ったら「DM送信日」、返信があれば「返信」に書く。
- 条件に合うが今日は選ばなかった人は `予備`。次の日はまず新しい投稿を探し、足りない分を予備から新しい順に選ぶ。
- 除いた人も理由をつけて `除外` で残す（同じ人をもう一度調べないため）。
