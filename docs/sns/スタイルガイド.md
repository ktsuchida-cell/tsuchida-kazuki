# Xの投稿スタイルガイド（@metaoripa_）

> **2026-10-28 時点は仮。** 実際の投稿をまだ分析していない（x.com を開けないため）。
> 投稿データを `sns/posts/` に入れて `python -m oripa.sns analyze` を実行したら、
> [投稿分析.md](投稿分析.md) を根拠に「2. 文体」を埋め、`sns/templates/` と `sns/rules.toml` も合わせて直す。

## 1. 投稿の種類

| 種類 | 目的 | いつ | 必ず入れること |
| --- | --- | --- | --- |
| 新ガチャ告知 | 新しいガチャの公開を知らせて、サイトに来てもらう | 公開時（予告するなら前日も） | ガチャ名・1回の価格・総口・目玉・URL |
| 当選報告 | 当たりが本当に入っていると伝える | 当たりが出たとき | ガチャ名・当たったカード |
| 残り口数 | 販売中のガチャの残りと、残っている当たりを知らせる | 残りが少なくなったとき | 投稿直前に確かめた残り口数・残っている当たり |
| プレゼント企画 | フォロー・リポストでフォロワーを増やす | 企画のとき | 賞品・人数・応募方法・締切・当選の連絡方法 |
| お知らせ | メンテナンス・不具合・発送などの連絡 | 必要なとき | 日時・影響・対応 |

種類の判定キーワードは `sns/rules.toml`。分析で「その他」が多ければ種類やキーワードを足す。

## 3. 数字の書き方（分析と関係なく守る）

- 1回の価格・総口・アド確率・還元率は、パックの構築結果から入れる（`draft` が入れる）。手で打たない。
- 還元率・アド確率は、実際より良く見える丸め方をしない（還元率は切り捨て、アド確率の分母は切り上げ）。
- 「全部PSA10」は、当たりが全部PSA10のときだけ書く（2026/10/14〜は全部PSA10が前提）。
- 残り口数・残っている当たりは、投稿する直前にサイトで確かめる。推測で書かない。
- 投稿する前に `check` を通す。エラーが残ったまま投稿しない。

## 4. 書かないこと

- お金に替えられる・お金が増えると受け取られる表現（換金・現金化・稼げる・儲かる・投資）。
- 結果を保証する表現（必ず当たる・損しない・元が取れる）。
- 根拠のない最上級表現（No.1・業界最高・最安・最高還元）。
- 期限のない「今だけ」「期間限定」、実際の残りと合わない「残りわずか」。
- 当選者のユーザー名や個人が分かる情報（本人の同意がないとき）。
- 他社の名前を出した比較。

競合の告知文を参考にするときは、[競合一覧の備考](../competitors/README.md)（集団訴訟の被告・消費者庁への申出対象）に注意する。
購入を条件にしたプレゼント企画は景品の上限がある（景品表示法）ので、企画する前に確認する。
