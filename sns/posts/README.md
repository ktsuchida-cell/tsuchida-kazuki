# 投稿データ

X（@metaoripa_）から書き出した過去の投稿を置く。`python -m oripa.sns analyze` がこのフォルダの `.js` `.json` `.csv` `.txt` を全部読む。

- データのアーカイブなら、zip の中の `data/tweets.js` だけを置く（zip ごと置かない。DMやログイン履歴が入っている）。
- アナリティクスの CSV、手で貼ったテキスト（投稿を `---` だけの行で区切る）でもよい。

書き出し方は [docs/sns/README.md](../../docs/sns/README.md) の「1. 投稿データを入れる」。
