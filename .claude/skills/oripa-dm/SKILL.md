# DM先の選定（毎日5名）

条件・送らない人・優先順位・文面は `docs/dm/README.md`。記録は `docs/dm/DM候補リスト.csv`。

## 手順

1. **リストを読む**：`docs/dm/DM候補リスト.csv` の全員（送る・予備・除外）を覚えておく。この人たちは新しく調べ直さない。

2. **Web検索で投稿を探す**（Xは直接開けない。WebFetch も402で失敗する）。`site:x.com` をつけて、例えば次で検索する。
   - 当選報告のハッシュタグ：`#DOPA当選報告`、`#トレカセンター当選報告`、`#オリくじ当選報告`、`#オリパワン当選報告`、`#クローブオリパ当選報告`
   - 言い回し：`オリパ 当たった`、`オリパ 神引き`、`おすすめのオンラインオリパ 教えて`、`オリパ 乗り換え`
   - 他のサイト名：`docs/competitors/` の一覧の大手（ポケカを扱う稼働中のオンラインオリパ）
   - 公式アカウントの返信（「おめでとう」「ナイス神引き」）に出てくる @ユーザー名 も候補にしてよい。

3. **投稿日を出す**：URLの status の後ろの数字から計算する（`docs/dm/README.md` の1行）。検索結果の日付の説明はずれることがあるので、こちらを使う。

4. **条件で絞る**：README の「選ぶ条件」「送らない人」に当てはめる。投稿にメタオリパが出てくる人は除く。迷う人は予備にして、メモに理由を書く。

5. **5名を選ぶ**：README の優先順位で、新しく見つけた人を先に、足りない分を予備から新しい順に選ぶ。5名に届かなければ、届かなかったと正直に書く（条件をゆるめて数をそろえない）。

6. **リストに書く**：送る5名・新しく見つけた予備・除外を CSV に追記する（BOMつきUTF-8のまま。Pythonの csv で書く）。予備から選んだ人は区分を `送る` に変え、選定日を入れる。

7. **結果を見せる**：5名の表（アカウント・投稿URL・投稿日・サイト・選んだ理由）と、1人ずつの DM 文面を出す。最後に「送る前にプロフィールで確認すること」（README）を短く添える。

## 注意

- DMは人が手で送る。こちらから送ったり、自動で送る仕組みを作ったりしない。
- 投稿内容を作らない。検索結果に出た文面だけを根拠にし、分からないことは「確認する」とメモに書く。
- 検索で拾えるのは数か月前の投稿が多い。新しい投稿が見つからない日は、そのことを伝える。
