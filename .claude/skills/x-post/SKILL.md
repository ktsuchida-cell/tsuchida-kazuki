# メタオリパ X投稿

仕組みは `docs/sns/README.md`。ツールは `python -m oripa.sns`（analyze / draft / check）。
x.com はこの環境から開けない（ログインが要る）。ミラーサイトなどで取りに行かず、書き出したデータ（`sns/posts/`）を使う。

## 投稿を分析するとき

1. `sns/posts/` に投稿データ（`tweets.js` / `*.csv` / `*.txt`）があるか確かめる。
   なければユーザーに書き出して置いてもらう（`docs/sns/README.md` の「1. 投稿データを入れる」を案内する）。
2. `python -m oripa.sns analyze` → `docs/sns/投稿分析.md`
3. 分析を読んで直す:
   - `sns/rules.toml`: 「その他」に入った投稿を見て、種類・キーワードを足す。ハッシュタグを実際に使っているものにする。
     直したら analyze をやり直す。
   - `docs/sns/スタイルガイド.md`: 「2. 文体」を埋める。根拠の数字も書く。冒頭の「仮」の注記を外す。
   - `sns/templates/`: 投稿分析.md の5章（お手本）の構成・書き出し・絵文字・ハッシュタグに合わせて書き直す。
4. 分かったことを表で示す（種類の割合、反応がよい種類・時間帯、書き方の特徴、上位の投稿）。
   件数が少ない（30件くらいまで）ときや、反応のデータがないときは、傾向と言い切らない。

## 投稿文を作るとき

1. **種類を決める**（新ガチャ告知・当選報告・残り口数・プレゼント企画・お知らせ）。
2. **数字入りのたたき台を出す**:
   `python -m oripa.sns draft packs/<パック>.toml --type <種類> [--remaining N] [--set 項目=値]`
   - パックの定義ファイルがなければ、先に `oripa-pack` スキルでパックを作る（数字を推測で書かない）。
   - 当選報告の `card`、残り口数の `remaining` と `left`（残っている当たり）、プレゼント企画の `prize` `winners` `deadline` は
     ユーザーに聞く（サイトで確かめた値）。推測で埋めない。
3. **書き直す**: `docs/sns/スタイルガイド.md` と `docs/sns/投稿分析.md` の5章（お手本）に合わせて、2〜3案にする。
   - 数字・カード名はたたき台から変えない。還元率などを足すときは構築結果の値（`{return_rate}` など）を使う。
   - 投稿分析.md がない（データをまだ入れていない）ときは、文体は仮のテンプレートのままだと伝える。
4. **チェック**: 案を `---` だけの行で区切って `out/sns/<日付>_<種類>.txt` に書き、
   `python -m oripa.sns check out/sns/<ファイル>.txt --pack packs/<パック>.toml [--remaining N]`
   - エラーがなくなるまで直す。注意が出たら、理由と確かめることをユーザーに伝える。
5. **見せる**: 各案と文字数（X の数え方で ◯/280）を示す。投稿はしない（人が確認して投稿する）。

## 注意

- 書かないこと（換金・稼げる・必ず当たる・根拠のないNo.1 など）は `docs/sns/スタイルガイド.md` の4章と `sns/rules.toml`。
- 当選者のユーザー名は、本人の同意がなければ出さない。
- 購入を条件にしたプレゼント企画は景品の上限がある（景品表示法）。企画の中身を決める前にユーザーに確認する。
- 文字数は X の数え方（日本語・絵文字は2、URLは23）。`python -m oripa.sns check` の値を使い、目で数えない。
