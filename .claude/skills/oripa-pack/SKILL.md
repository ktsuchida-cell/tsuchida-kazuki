# メタオリパ パック作成

ルールの詳細は `docs/パック作成手順.md`。ツールは `python -m oripa <定義ファイル.toml>`。

## 手順

1. **入力をそろえる**（足りなければユーザーに聞く。推測で仕入れ価格を作らない）
   - 当たりカード: 賞（S爆 / S）、名称、仕入れ価格、スニダンURL、在庫かどうか、枚数
   - 一回の価格と総口（指定がなければ早見表から近い過去パックを提案する）
   - 目標還元率（既定 97%、上限 100%）
   - テーマを決めるときは、`docs/competitors/` の一覧（ポケカを扱う稼働中のオンラインオリパ）で同じテーマのガチャがないか検索して確かめる。競合調査はこの一覧のサイトを基準にする。
     - 結果は `docs/competitors/競合チェック記録.md` に日付・根拠のリンクつきで追記する。
     - 「競合では見つからなかった」と書くのは、大手（DOPA!、クローブオリパ、日本トレカセンター、オリくじ、オリパワン、ポケットクロス など）を調べてから。
     - PSA10確定オリパは大手も定期的に出しているので、PSA10だけを違いとして説明しない。
   - スプレッドシートやCSVで渡されたら `cards_csv` で読み込む。

2. **定義ファイルを作る**: `packs/template.toml` をコピーして `packs/<YYYY-MM-DD>_<ガチャ名>.toml`。
   - 目玉は在庫カードを優先し `stock = true`。
   - ハズレ枠は A（一回より高いPT）を `count = "auto"`、B/C（低PT）を `count = "rest"` にすると、
     目標還元率を超えない最大のA枚数を自動で決める。

3. **実行する**: `python -m oripa packs/<ファイル>.toml`
   - エラーになったら原因（還元率超過、当たりだけで目標超え など）を読み、
     総口・一回の価格・当たりの枚数・Aの PT を調整して再実行する。

4. **結果を見せる**: 構築表と、還元率・概算収支・アド確率・新規仕入額/在庫活用額を表で示す。
   - 還元率 100% 超は出さない（ユーザーが課金ガチャ・お詫び等で明示した場合だけ `max_return_rate` を上げる）。
   - 概算収支がマイナスなら必ず指摘し、改善案（総口を増やす、S賞を1枚減らす等）を出す。
   - xlsx（`out/` 以下）は構築スプレッドシートに取り込んで村佐さんの確認に回す、と案内する。

## 注意

- 掛け率の既定は S爆 1.4 / S 1.3（手数料 1.05）。高額の目玉だけ 1.45〜1.5 にすることがある。
- 当選番号は `seed` で固定される。作り直すときに番号を変えたいなら `seed` を変える。
- 当選番号は高いカードほど後ろになり、一番高いカードは総口の9割以降になる（ツールが自動でやる）。
  構築シートに手で番号を入れるときも、この順番を崩さない。
- 構築スプレッドシート本体（共有シート）を直接書き換えない。xlsx を渡して人が取り込む。
